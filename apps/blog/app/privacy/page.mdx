## 1. 信息收集与日志文件

像大多数标准网站服务器一样，当您访问本站时，服务器会自动记录常规的访问日志信息（Log Files）。这些信息包括但不限于：
- 您的互联网协议（IP）地址；
- 浏览器类型及版本；
- 访问日期与时间；
- 页面浏览记录与跳转来源（Referrer）。

> [!NOTE]
> 日志用于安全防御、性能诊断与访问分析。请勿在页面 URL、搜索词或反馈中填写密码、密钥等敏感信息。

本站使用 Cloudflare 提供网络分发与安全防护，并接入 Umami、百度统计与 Cloudflare Web Analytics 分析访问情况。不同服务可能处理页面地址、来源、设备及访问事件；具体处理方式请分别参阅 [Umami 文档](https://umami.is/docs)、[百度隐私政策](https://privacy.baidu.com/policy)与 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。Umami 脚本经本站 `/stats/` 转发，不表示所有第三方统计请求都在浏览器本地处理。

## 2. Cookie 与网络信标（Cookies & Web Beacons）

Cookie 是保存在您计算机或移动设备上的小型文本文件。本站及本站所接入的第三方服务可能使用 Cookie 来记录偏好设置、优化页面响应速度以及投放相关内容。

本站还使用浏览器本地存储保存主题偏好，并通过 Service Worker 缓存部分页面与静态资源。清除本站的网站数据可移除这些本地记录；这不会自动删除第三方服务已接收的数据。

本站为 Google 标签设置默认拒绝广告存储。同意弹窗的选择需要通过 Google CMP 传递给标签；仅加载广告脚本不表示您已同意使用 Cookie。

您可以通过浏览器的设置随时管理或清除已保存的 Cookie，也可以选择在浏览器中完全禁用 Cookie 功能。请注意，禁用 Cookie 可能会影响部分站内功能的正常使用。

## 3. Google AdSense 与第三方广告政策

本站配置了 **Google AdSense** 广告代码。实际广告展示取决于 Google 的审核、投放状态与相关设置。广告服务可能使用下列信息与机制：

- **第三方 Cookie 投放**：第三方供应商（包括 Google）会使用 Cookie 根据用户之前对本网站或互联网其他网站的访问记录向用户投放广告；
- **广告 Cookie 的使用**：Google 及其合作伙伴使用广告 Cookie，使其能够根据用户对本网站和/或互联网其他网站的访问情况，向用户投放适切的广告；
- **停用个性化广告**：
  - 您可以访问 [Google 广告设置（Ads Settings）](https://adssettings.google.com/) 随时选择停用个性化广告；
  - 您也可以访问 [www.aboutads.info](https://www.aboutads.info/) 停用参与该倡议的第三方供应商的个性化广告 Cookie。

## 4. 外部链接与第三方服务

本站文章中可能包含指向外部第三方网站（如 GitHub、官方文档、参考资料等）的超链接。我们对这些第三方网站的隐私权政策、内容和行为概不负责。建议您在离开本站并访问任何第三方网站时，仔细阅读其各自的隐私声明。

文章评论使用 [Giscus](https://giscus.app/zh-CN)，基于 GitHub Discussions。发表评论可能需要登录 GitHub，公开评论会按 GitHub 的规则保存并展示。请勿在评论中公开敏感信息；有关账号与数据处理，请参阅 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

个人主页迁入“关于我”页后，头像、网站预览、开源贡献截图和普通贡献热力图由本站提供；Star / Fork 数量通过浏览器请求 GitHub 公共 API 更新。访问关于页时，这些请求可能向 GitHub 传递 IP 地址和浏览器信息；请求失败时保留注明日期的原站快照。贡献热力图使用本站保存的静态快照，不会把访问者的信息用于生成贡献图。

本站不提供站内账号、文件上传或联系表单。点击邮件链接会交由您选择的邮件程序处理。您可以在浏览器中阻止第三方请求，网站正文和工具链接仍可访问。
